# My Dictionary Support

## Before opening an issue

1. Try the lookup again after a short wait. The free staging service may be sleeping after inactivity.
2. Confirm that your browser or device is online.
3. Export a backup before clearing local data or changing browsers.

## What to include

Include your browser and device, the word that failed, the approximate time, the screen or message shown, and whether retrying helped. Never attach private notes, backup files, passwords, API keys, or authentication details.

## Report a problem

Open the [My Dictionary issue tracker](https://github.com/Tanukohli09/my_dictionary/issues). Search existing issues first, then provide the smallest reproducible description.

For security reports, do not publish an exploit or secret in a public issue. The repository owner should enable a private GitHub security reporting channel before a broad public launch.

See the repository [security policy](SECURITY.md) for the safe reporting process.
